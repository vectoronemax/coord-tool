Vector的坐标转换器离线版

WGS-84 ⇄ GCJ-02 ⇄ BD-09 六向互转：单点即时换算，或整表批量转换，自动揪出写反、越界、国外、海上的坏点。

可以直接把「经度,纬度」整段粘贴进经度框，会自动拆开。

② 选择经纬度列和源坐标系

列和源坐标系是按列名猜的，请核对：列名写着 WGS-84 的数据，实际可能是从国内地图上取的 GCJ-02。

算法说明

  • WGS-84 → GCJ-02：开源社区流传的公开加偏公式（克拉索夫斯基椭球参数 + 正弦扰动项）。非官方发布，主流开源库都用这一版；中国范围框外不加偏。
  • GCJ-02 → BD-09：百度公开的 x_pi 公式。
  • 反算（GCJ-02 → WGS-84、BD-09 → GCJ-02）：公式没有解析逆，从目标点出发，用正算的残差修正 5 轮，往返误差 < 1 毫米（外滩实测逐轮 479 m → 2.2 m → 7 mm → 0.025 mm → 0）；WGS-84 ⇄ BD-09 经 GCJ-02 中转。
  • 偏移距离：转换前后两组数字画在同一张图上的球面距离（半正矢公式，地球平均半径 6371008.8 米）。
  • 校验：只有正常的点才转换，问题点不转换、给出原因。每个点只标一个最能说明问题的类型，依次判断：缺失或非数字 → (0, 0) → 落在省级区内即正常 → 交换经纬度后落进省级区＝写反 → 超出 ±180 / ±90 → 中国范围框外＝国外 → 其余＝框内但不在省级区（海上或邻国）。
  • 省级边界：阿里云 DataV.GeoAtlas（GCJ-02），已内嵌在本文件里。边界经过简化，紧贴海岸的点可能被误标，说明里会给出最近省份和距离。
  • 与 Python 版 coord_core.py 同一套算法和校验规则；本离线版没有地图预览（地图底图需要联网加载）。
